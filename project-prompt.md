# Project Build Prompt

Build a production-quality E-commerce Data Analytics and Business Intelligence web application using realistic, reproducible dummy data.

## Product Goal

Create a premium analytics product for e-commerce owners, product managers, marketing teams, and business analysts. It must analyze revenue, profit, orders, customers, products, categories, inventory, discounts, marketing, payments, geography, retention, acquisition, AOV, conversion-related metrics, returns, and refunds.

## Required Architecture

- Generate at least 5,000 customers, 500 products, 20,000 orders, 30,000 order items, 5,000 marketing records, 2,000 returns, and 20,000 payments.
- Cover 3–5 years with realistic seasonality and relationships.
- Keep data generation, analytics/API logic, and frontend presentation separate.
- Expose filtered REST endpoints for dashboard, sales, profit, orders, products, customers, categories, marketing, returns, and inventory.
- Calculate all metrics from datasets; never hardcode KPI values or insights.

## UI Requirements

Build a responsive SaaS dashboard inspired by Stripe, Shopify Analytics, Vercel, Linear, Power BI, and Tableau. Include navigation, global filters, KPI cards, charts, insights, tables, search, pagination, exports, loading states, empty states, error states, tooltips, and mobile support.

## Core Metrics

Revenue, gross profit, net profit, profit margin, order status, customers, retention, AOV, conversion-related rates, refunds, returns, monthly/yearly trends, product and category performance, RFM/customer segments, geography, marketing ROAS/CAC, discounts, inventory status, and payment success.

## Quality Bar

Every visual must answer a business question. Use reusable components or clearly separated render functions. Keep calculations auditable, API responses aggregated, browser payloads bounded, and documentation professional. Validate generation, APIs, filters, exports, charts, and responsive layouts before completion.
